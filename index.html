FAQ

Frequently Asked Questions

Everything you need to know about Sodium File Manager editions.

What's the difference between Lite and Pro?
Lite is a lightweight edition using ~30MB RAM with core file management features (automatic sorting, real-time monitoring, custom rules, undo, statistics). Pro uses 30-60+ MB RAM and adds the YouTube Downloader, File Converter, Sodium Clean (disk cleanup), advanced regex rules, priority ordering, queue management, batch processing, FFmpeg integration, drag & drop, and system tray support.
Are both editions free?
Yes! Both Sodium File Manager Lite and Pro are completely free to download and use. No hidden charges, no premium tiers, no subscriptions.
Is my data uploaded to the cloud?
No. Both editions are 100% local. Your files never leave your machine. No cloud upload, no telemetry, no tracking. Everything runs offline.
Which edition should I choose?
Choose Lite if you want a lightweight, fast file manager with core features and minimal RAM usage. Choose Pro if you need advanced features like YouTube downloading, file conversion, Sodium Clean disk cleanup, regex rules, and more control over your file organization.
Do both editions work on Windows 11?
Yes, both editions are fully compatible with Windows 10 and Windows 11. They run as portable executables with no installation required. Just download and run.
Can I upgrade from Lite to Pro?
Yes! Simply download the Pro edition — it runs alongside Lite or replaces it. Both are portable, so you can keep both installed if you like.
Does Pro require FFmpeg?
FFmpeg is required for the YouTube Downloader and File Converter modules in Pro. The app includes an automatic FFmpeg installer — it will prompt you to install it when needed.
What is Sodium Clean?
Sodium Clean is the disk cleanup module included in the Pro edition. It helps you reclaim disk space by removing temporary files, browser cache, recycle bin contents, and other system junk — all from one place.
