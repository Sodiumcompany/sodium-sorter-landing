FAQ

Frequently Asked Questions

Everything you need to know about Sodium Sorter.

Is Sodium Sorter free?
Yes! Sodium Sorter is completely free to download and use. No hidden charges, no premium tiers — just a powerful file sorter for Windows.
Does Sodium Sorter work offline?
Absolutely. Sodium Sorter works completely offline. No internet connection is ever required to organize files automatically.
Is my data uploaded to the cloud?
No. Sodium Sorter is 100% local. Your files never leave your machine. There is no cloud upload, no telemetry, and no tracking — just pure file management software.
What file types can be organized?
Sodium Sorter supports all file types. Create rules for documents (.pdf, .docx), images (.jpg, .png), videos (.mp4, .avi), music (.mp3, .flac), archives (.zip, .rar), and any other extension.
Does Sodium Sorter support Windows 11?
Yes, Sodium Sorter is fully compatible with Windows 10 and Windows 11. It runs as a portable executable with no installation required.
Can I customize sorting rules?
Absolutely. Sodium Sorter lets you define unlimited custom rules based on file extension, name pattern, or regular expressions. You can enable, disable, and reorder rules freely — making it the most flexible folder organization tool.
